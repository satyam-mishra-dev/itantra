# iTantra — the offline multilingual semantic transceiver

**SIH 2026 · PS SIH26173 (ISRO) · Team Null Pointers**

Voice that travels as text. Push-to-talk speech is transcribed **on-device** in any of 10 Indian languages, compressed by **VarnaCode** to ~45 bytes per sentence, sent over whatever link survives — Wi-Fi, Bluetooth, a ₹1,650 LoRa node, or 0.3 s of audio through any analog radio — and re-synthesized as natural speech at the far end. Fully offline. Open-source only.

| | Measured (not estimated) |
|---|---|
| One spoken sentence on the wire | **45 B** — 169× less than cellular voice (AMR-NB), 889× less than raw (G.711) |
| VarnaCode, all 10 languages | **4.45–5.41 bits/char** — beats Unishox2 and SCSU head-to-head on identical sentences |
| Real human speech (FLEURS, int8 140 MB packs) | CER hi **2.9%** · bn 4.0% · te 7.8% · ml 9.2% · ta 13.9% · RTF 0.06 |
| Encrypted sentence (AES-128-GCM) | 73 B — still ~100× under cellular voice |
| Tests | 413 Python assertions across 8 suites · 127 firmware parity cases · 44 JUnit tests (byte-identical to Python via generated vectors) |
| APK | 54.9 MB incl. full speech runtime; two-phone loop proven on emulators incl. ALERT |

## Run it

```bash
# Reference pipeline + all tests
cd p0 && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # or see p0/README.md
.venv/bin/python test_p0.py            # 222 assertions
.venv/bin/python bench_compression.py  # VarnaCode vs UTF-8 / gzip / Unishox2 / SCSU / AMR / Codec2

# Android (needs JDK 17+, Android SDK 34; sherpa-onnx AAR download documented in app/README.md)
cd app && ./gradlew assembleDebug test

# Firmware (no hardware needed to compile)
cd firmware/lora-bridge && pio run && python3 test_frame_compat.py
```

Model packs (int8 STT ~140 MB + Piper TTS ~63 MB per language) are not in git — `app/README.md` has the conversion and sideload commands.

## Wave 3 — reliability, mesh, phrasebook, FEC, location (2026-09-15)

Built after reading all 76 public SIH26173 repos (`research/competitor-survey.md`): the field converges on ACK/retransmit, mesh, alert preemption and phrase codes, but nobody entropy-codes text, runs through an analog radio, ships LoRa firmware or a CAP bridge. Wave 3 closes the consensus gaps without changing a byte of the existing frame format — every feature is a new module with a Python reference, a Kotlin port, and generated byte-identity vectors between them.

| Feature | Python | Kotlin | What it does | Cost on the wire |
|---|---|---|---|---|
| Reliable delivery | `p0/reliable.py` | `Reliable.kt` | 7-byte delivery ACK/NACK, dedup by (seq, CRC) — restart-safe, gap→NACK, ALERT jumps the queue, 3/5 tries or store-and-forward with capped backoff | 7 B per ACK |
| Far-end speech policy | `p0/speak.py` | `Speak.kt` | danda → clause split (Piper otherwise says "पूर्णविराम"), 1,50,000 → "1 लाख 50 हज़ार" in 10 languages, units, acronyms; ALERT preempts at a clause boundary, resumes, plays twice | 0 |
| Phrasebook mode | `p0/phrasebook.py` | `Phrasebook.kt` | 32 emergency phrases × 10 languages as a **9–10 B language-neutral frame** (`lang=15`); receiver renders in *its* language — a Hindi "5 लोग घायल हैं" is spoken as Odia on an Odia phone with no MT model. Sender confirms; never auto-sent | 9–10 B vs 21–27 B text |
| Flood relay | `p0/relay.py` | `RelayTransport.kt` | multi-hop over any bearers (`lang=14` envelope), hop-limit TTL, restart-safe dedup, jitter; ACKs ride the flood back so reliability holds end-to-end across hops | +9 B when relayed |
| FEC (analog radio) | `p0/fec.py` | — | Reed–Solomon on the AFSK path with a raw demodulator ahead of the CRC gate; ≈2 dB gain: at 0 dB SNR frame success 3% → 77% (RS8) / 90% (RS16), at 2 dB 67% → 100% | +8 / +16 B |
| Location | `p0/frame.py` | `Frame.kt` | prosody-byte bit 6 flags a 6-byte lat/lon trailer (~1.3 m), encrypted when the frame is, ignored by old receivers | +7 B |

Verified by the testing session on two emulators with real packs: 3/3 delivered, 0 duplicates, ✓ on ACKs, phrase flow hi → or end-to-end; three consecutive app restarts delivered (that found and fixed the seq-only dedup bug). Thesis research behind the roadmap: `research/thesis-receiver-language.md`, `thesis-dtn.md`, `thesis-channel-adaptive.md`.

## Honesty notes

- All accuracy numbers are on desktop CPU; on-device RTF on a budget phone is the first thing Evaluation Mode measures on real hardware.
- A GTCRN speech-enhancement stage was measured and **rejected** — it raised CER at every SNR. We ship without a denoiser and say so.
- The arithmetic-coding VarnaCode v2 won by 0.03 bits/char and was **not** adopted; Huffman v1 stays the wire format.
- `p0/phrasebook.json` translations are a first draft awaiting native-speaker review per language.
- Neural TTS voices exist (commercial-OK) for en, hi, bn, mr, ml, te; gu, kn, ta, or are text-only until the AI4Bharat Indic-TTS (MIT) FastPitch export is written.
- A fresh install on Android 14 crashed on first open (mic foreground service before the RECORD_AUDIO grant) — every earlier run had used `adb install -g`. Fixed; see `app/TESTING.md`.
